This site hosts Twitchy's static OAuth return page. Start sign-in from the native Twitchy app.

Twitchy now uses Public Device Code Flow for automatic sign-in renewal. Confirm Client Type: Public in the Developer Console, then choose Sign in with Twitch in the app. No redirect page is needed for this flow.

For the optional legacy browser flow, use this exact URL in the Twitch Developer Console and Twitchy’s Advanced redirect URI setting:

https://rafaelreverberi.github.io/Twitchy/oauth-callback.html
